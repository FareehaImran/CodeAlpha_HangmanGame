# CodeAlpha Hangman Game

A text-based Hangman game made in Python for the CodeAlpha internship (Task 1).

## How to play
- The computer picks a random word from a list of 5 words.
- Guess one letter at a time.
- You can make 6 wrong guesses before you lose.

## How to run
python hangman.py

## Concepts used
random, while loop, if-else, strings, lists, functions
